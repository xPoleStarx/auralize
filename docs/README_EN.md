**Auralize** 🎨 is an interactive web platform that allows users to discover and develop their creative "auras." Through visual quizzes 🎥, personal preferences 🌈, and free inputs, we aim to reveal everyone's inner creativity by generating AI-powered **artworks** 🖼️, **stories** 📖, and **sounds** 🎶. Aligned with Lenovo's *"Your aura is unlimited"* campaign, this project visualizes users' creative potential with AI and offers a community-focused experience! 🚀

---

## 🎯 Objective
Auralize is much more than an application that produces one-time artwork! 🌌 It aims to be a platform offering a personalized experience where users can explore their creative journeys, evolving over time. Discovering **something new** ✨ in each visit and expressing creativity in different ways encourages users to return regularly. 💡

---

## ✨ Key Features ✨
1. **🎮 Dynamic and Interactive Entry Interface**  
   - Multi-step, gamified *"Creative Discovery Journey"*.  
   - Visual quizzes 🖼️, color palettes 🎨, and free inputs analyze moods and creative tendencies.

2. **🌟 Rich and Evolving Outputs**  
   - AI-generated artworks 🎨, stories/poems 📜, and audio clips 🎵.  
   - Users can *"evolve"* their works over time (e.g., changing style, adding details) 🔄.

3. **📊 Personal Aura Profile**  
   - A *"Creative Journal"* for past works and preferences.  
   - *"Aura Evolution"* graph showing changes in creative tendencies over time 📈.

4. **🌐 Community and Social Interaction**  
   - A gallery to share your works 🖼️.  
   - Social dimension with comments 💬, likes ❤️, and weekly themes.

5. **🏆 Gamification and Rewards**  
   - Badges 🥇, point system 🎯, and leaderboards 📋 for motivation.  
   - Weekly competitions and interaction rewards 🎁.

---

## 🛠️ AI Technologies Used
- **🖼️ Image Generation:** Unique artworks with *Stable Diffusion*.  
- **📝 Text Generation:** Personalized stories and poems with *GPT-based models*.  
- **🎶 Audio Generation (Optional):** Aura-themed melodies with *AudioLDM*.  

These technologies are combined to transform user inputs into **rich and creative content**! ⚙️

## ⚙️ Setup
### 📋 Requirements
- **Node.js** (v16 or above)  
- **Python** (v3.8 or above)  
- API access or local installation for Stable Diffusion, GPT, and AudioLDM models  

### 🚀 Steps
1. Clone the repository and run:
   ```bash
   git clone https://github.com/xPoleStarx/auralize.git
   cd auralize

   npm install
   pip install -r requirements.txt

   npm start
   ```
