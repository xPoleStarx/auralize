**Auralize** 🎨 es una plataforma web interactiva que permite a los usuarios descubrir y desarrollar sus "auras" creativas. A través de cuestionarios visuales 🎥, preferencias personales 🌈 y entradas libres, nuestro objetivo es revelar la creatividad interior de cada persona generando **obras de arte** 🖼️, **historias** 📖 y **sonidos** 🎶 impulsados por IA. En línea con la campaña de Lenovo *"Tu aura es ilimitada"*, este proyecto visualiza el potencial creativo de los usuarios con IA y ofrece una experiencia centrada en la comunidad. 🚀

---

## 🎯 Objetivo
¡Auralize es mucho más que una aplicación que produce obras de arte de un solo uso! 🌌 Aspira a ser una plataforma que ofrece una experiencia personalizada donde los usuarios pueden explorar sus viajes creativos, evolucionando con el tiempo. Descubrir **algo nuevo** ✨ en cada visita y expresar la creatividad de diferentes maneras anima a los usuarios a regresar regularmente. 💡

---

## ✨ Características Principales ✨
1. **🎮 Interfaz de Entrada Dinámica e Interactiva**  
   - Un *"Viaje de Descubrimiento Creativo"* multi-etapa y gamificado.  
   - Los cuestionarios visuales 🖼️, paletas de colores 🎨 y entradas libres analizan estados de ánimo y tendencias creativas.

2. **🌟 Resultados Ricos y Evolutivos**  
   - Obras de arte 🎨, historias/poemas 📜 y clips de audio 🎵 generados por IA.  
   - Los usuarios pueden *"evolucionar"* sus obras con el tiempo (por ejemplo, cambiar el estilo, agregar detalles) 🔄.

3. **📊 Perfil de Aura Personal**  
   - Un *"Diario Creativo"* para obras y preferencias pasadas.  
   - Gráfica de *"Evolución del Aura"* mostrando los cambios en las tendencias creativas a lo largo del tiempo 📈.

4. **🌐 Comunidad e Interacción Social**  
   - Una galería para compartir tus obras 🖼️.  
   - Dimensión social con comentarios 💬, me gusta ❤️ y temas semanales.

5. **🏆 Gamificación y Recompensas**  
   - Insignias 🥇, sistema de puntos 🎯 y tablas de clasificación 📋 para motivación.  
   - Competencias semanales y recompensas por interacción 🎁.

---

## 🛠️ Tecnologías de IA Utilizadas
- **🖼️ Generación de Imágenes:** Obras de arte únicas con *Stable Diffusion*.  
- **📝 Generación de Texto:** Historias y poemas personalizados con *modelos basados en GPT*.  
- **🎶 Generación de Audio (Opcional):** Melodías temáticas de aura con *AudioLDM*.  

Estas tecnologías se combinan para transformar las entradas de los usuarios en **contenido rico y creativo**. ⚙️

## ⚙️ Configuración
### 📋 Requisitos
- **Node.js** (v16 o superior)  
- **Python** (v3.8 o superior)  
- Acceso API o instalación local para modelos Stable Diffusion, GPT y AudioLDM  

### 🚀 Pasos
1. Clona el repositorio y ejecuta:
   ```bash
   git clone https://github.com/xPoleStarx/auralize.git
   cd auralize

   npm install
   pip install -r requirements.txt

   npm start
   ```
