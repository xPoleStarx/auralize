**Auralize** 🎨 è una piattaforma web interattiva che permette agli utenti di scoprire e sviluppare le proprie "aure" creative. Attraverso quiz visivi 🎥, preferenze personali 🌈 e input liberi, miriamo a rivelare la creatività interiore di ciascuno generando **opere d'arte** 🖼️, **storie** 📖 e **suoni** 🎶 alimentati dall'IA. In linea con la campagna di Lenovo *"La tua aura è illimitata"*, questo progetto visualizza il potenziale creativo degli utenti con l'IA e offre un'esperienza incentrata sulla comunità! 🚀

---

## 🎯 Obiettivo
Auralize è molto più di un'applicazione che produce opere d'arte una tantum! 🌌 Mira a essere una piattaforma che offre un'esperienza personalizzata dove gli utenti possono esplorare i propri percorsi creativi, evolvendosi nel tempo. Scoprire **qualcosa di nuovo** ✨ ad ogni visita ed esprimere la creatività in modi diversi incoraggia gli utenti a tornare regolarmente. 💡

---

## ✨ Caratteristiche Principali ✨
1. **🎮 Interfaccia di Ingresso Dinamica e Interattiva**  
   - Un *"Viaggio di Scoperta Creativa"* a più fasi e gamificato.  
   - Quiz visivi 🖼️, palette di colori 🎨 e input liberi analizzano umori e tendenze creative.

2. **🌟 Risultati Ricchi ed Evolutivi**  
   - Opere d'arte 🎨, storie/poesie 📜 e clip audio 🎵 generati dall'IA.  
   - Gli utenti possono far *"evolvere"* le loro opere nel tempo (ad esempio, cambiando stile, aggiungendo dettagli) 🔄.

3. **📊 Profilo Aura Personale**  
   - Un *"Diario Creativo"* per opere e preferenze passate.  
   - Grafico di *"Evoluzione dell'Aura"* che mostra i cambiamenti nelle tendenze creative nel tempo 📈.

4. **🌐 Comunità e Interazione Sociale**  
   - Una galleria per condividere le tue opere 🖼️.  
   - Dimensione sociale con commenti 💬, like ❤️ e temi settimanali.

5. **🏆 Gamification e Premi**  
   - Badge 🥇, sistema di punti 🎯 e classifiche 📋 per motivazione.  
   - Competizioni settimanali e premi per l'interazione 🎁.

---

## 🛠️ Tecnologie di IA Utilizzate
- **🖼️ Generazione di Immagini:** Opere d'arte uniche con *Stable Diffusion*.  
- **📝 Generazione di Testo:** Storie e poesie personalizzate con *modelli basati su GPT*.  
- **🎶 Generazione Audio (Opzionale):** Melodie a tema aura con *AudioLDM*.  

Queste tecnologie sono combinate per trasformare gli input degli utenti in **contenuti ricchi e creativi**! ⚙️

## ⚙️ Configurazione
### 📋 Requisiti
- **Node.js** (v16 o superiore)  
- **Python** (v3.8 o superiore)  
- Accesso API o installazione locale per modelli Stable Diffusion, GPT e AudioLDM  

### 🚀 Passaggi
1. Clona il repository ed esegui:
   ```bash
   git clone https://github.com/xPoleStarx/auralize.git
   cd auralize

   npm install
   pip install -r requirements.txt

   npm start
   ```
