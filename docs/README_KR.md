**Auralize** 🎨 는 사용자가 창의적인 "오라"를 발견하고 발전시킬 수 있는 인터랙티브 웹 플랫폼입니다. 시각적 퀴즈 🎥, 개인 선호도 🌈, 자유 입력을 통해 AI 기반의 **예술 작품** 🖼️, **이야기** 📖, **소리** 🎶 를 생성하여 모든 사람의 내면 창의성을 드러내는 것을 목표로 합니다. 레노버의 *"당신의 오라는 무한합니다"* 캠페인과 함께, 이 프로젝트는 AI로 사용자의 창의적 잠재력을 시각화하고 커뮤니티 중심의 경험을 제공합니다! 🚀

---

## 🎯 목표
Auralize는 일회성 예술 작품을 만드는 애플리케이션 그 이상입니다! 🌌 시간이 지남에 따라 발전하는 창의적인 여정을 탐색할 수 있는 개인화된 경험을 제공하는 플랫폼이 되고자 합니다. 매 방문마다 **새로운 것**을 발견하고 ✨ 다양한 방식으로 창의성을 표현하는 것은 사용자가 정기적으로 돌아오도록 장려합니다. 💡

---

## ✨ 주요 기능 ✨
1. **🎮 역동적이고 상호작용적인 입력 인터페이스**  
   - 다단계, 게임화된 *"창의적 발견 여행"*.  
   - 시각적 퀴즈 🖼️, 색상 팔레트 🎨 및 자유 입력으로 기분과 창의적 경향 분석.

2. **🌟 풍부하고 진화하는 결과물**  
   - AI가 생성한 예술 작품 🎨, 이야기/시 📜, 오디오 클립 🎵.  
   - 사용자는 시간이 지남에 따라 작품을 *"진화"*시킬 수 있습니다(예: 스타일 변경, 세부 사항 추가) 🔄.

3. **📊 개인 오라 프로필**  
   - 과거 작품과 선호도를 위한 *"창의적 일지"*.  
   - 시간에 따른 창의적 경향의 변화를 보여주는 *"오라 진화"* 그래프 📈.

4. **🌐 커뮤니티 및 소셜 상호작용**  
   - 작품을 공유할 수 있는 갤러리 🖼️.  
   - 댓글 💬, 좋아요 ❤️, 주간 테마가 있는 소셜 차원.

5. **🏆 게임화 및 보상**  
   - 동기부여를 위한 배지 🥇, 포인트 시스템 🎯, 리더보드 📋.  
   - 주간 경쟁 및 상호작용 보상 🎁.

## 🛠️ 사용된 AI 기술
- **🖼️ 이미지 생성:** *Stable Diffusion*으로 독특한 예술 작품 생성.  
- **📝 텍스트 생성:** *GPT 기반 모델*로 개인화된 이야기와 시 생성.  
- **🎶 오디오 생성(선택 사항):** *AudioLDM*으로 오라 테마 멜로디 생성.  

이러한 기술들은 사용자 입력을 **풍부하고 창의적인 콘텐츠**로 변환하기 위해 결합되었습니다! ⚙️

## 🤝 캠페인 기여
"Auralize"는 레노버의 *"당신의 오라는 무한합니다"* 캠페인을 지원하여 창의성을 촉진하고 광범위한 청중에게 도달하는 것을 목표로 합니다. 소셜 미디어 공유 기능 📲 및 커뮤니티 갤러리를 통해 캠페인의 바이럴 확산을 증가시키고 **레노버 요가 오라 에디션**의 AI 파워를 강조합니다. 🌍

## ⚙️ 설정
### 📋 요구 사항
- **Node.js** (v16 이상)  
- **Python** (v3.8 이상)  
- Stable Diffusion, GPT 및 AudioLDM 모델용 API 액세스 또는 로컬 설치  

### 🚀 단계
1. 리포지토리를 복제하고 실행:
   ```bash
   git clone https://github.com/xPoleStarx/auralize.git
   cd auralize

   npm install
   pip install -r requirements.txt

   npm start
   ```
