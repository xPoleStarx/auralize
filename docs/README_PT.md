**Auralize** 🎨 é uma plataforma web interativa que permite aos usuários descobrirem e desenvolverem suas "auras" criativas. Através de quizzes visuais 🎥, preferências pessoais 🌈 e entradas livres, nosso objetivo é revelar a criatividade interior de cada pessoa gerando **obras de arte** 🖼️, **histórias** 📖 e **sons** 🎶 impulsionados por IA. Alinhado com a campanha da Lenovo *"Sua aura é ilimitada"*, este projeto visualiza o potencial criativo dos usuários com IA e oferece uma experiência focada na comunidade! 🚀

---

## 🎯 Objetivo
Auralize é muito mais do que um aplicativo que produz obras de arte de uso único! 🌌 Aspira ser uma plataforma que oferece uma experiência personalizada onde os usuários podem explorar suas jornadas criativas, evoluindo com o tempo. Descobrir **algo novo** ✨ em cada visita e expressar a criatividade de diferentes maneiras incentiva os usuários a retornarem regularmente. 💡

---

## ✨ Principais Características ✨
1. **🎮 Interface de Entrada Dinâmica e Interativa**  
   - Uma *"Jornada de Descoberta Criativa"* multi-etapa e gamificada.  
   - Quizzes visuais 🖼️, paletas de cores 🎨 e entradas livres analisam humores e tendências criativas.

2. **🌟 Resultados Ricos e Evolutivos**  
   - Obras de arte 🎨, histórias/poemas 📜 e clipes de áudio 🎵 gerados por IA.  
   - Os usuários podem *"evoluir"* suas obras ao longo do tempo (por exemplo, mudar estilo, adicionar detalhes) 🔄.

3. **📊 Perfil de Aura Pessoal**  
   - Um *"Diário Criativo"* para obras e preferências passadas.  
   - Gráfico de *"Evolução da Aura"* mostrando mudanças nas tendências criativas ao longo do tempo 📈.

4. **🌐 Comunidade e Interação Social**  
   - Uma galeria para compartilhar suas obras 🖼️.  
   - Dimensão social com comentários 💬, curtidas ❤️ e temas semanais.

5. **🏆 Gamificação e Recompensas**  
   - Emblemas 🥇, sistema de pontos 🎯 e tabelas de classificação 📋 para motivação.  
   - Competições semanais e recompensas de interação 🎁.

## 🛠️ Tecnologias de IA Utilizadas
- **🖼️ Geração de Imagens:** Obras de arte únicas com *Stable Diffusion*.  
- **📝 Geração de Texto:** Histórias e poemas personalizados com *modelos baseados em GPT*.  
- **🎶 Geração de Áudio (Opcional):** Melodias temáticas de aura com *AudioLDM*.  

Estas tecnologias são combinadas para transformar as entradas dos usuários em **conteúdo rico e criativo**! ⚙️

## ⚙️ Configuração
### 📋 Requisitos
- **Node.js** (v16 ou superior)  
- **Python** (v3.8 ou superior)  
- Acesso à API ou instalação local para modelos Stable Diffusion, GPT e AudioLDM  

### 🚀 Passos
1. Clone o repositório e execute:
   ```bash
   git clone https://github.com/xPoleStarx/auralize.git
   cd auralize

   npm install
   pip install -r requirements.txt

   npm start
   ```
